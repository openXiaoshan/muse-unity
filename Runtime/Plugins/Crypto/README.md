# Muse crypto dependency

BouncyCastle.Cryptography 2.6.2, official NuGet package, `lib/netstandard2.0`.
Source: https://www.nuget.org/packages/BouncyCastle.Cryptography/2.6.2
Only the portable managed DLL and its upstream license are included.
Used for X25519 and AES-GCM by the optional Muse object; no native crypto process or local bridge.
