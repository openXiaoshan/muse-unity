# Security

Do not post credential leaks or exploitable private details in public issues. Use the repository's private vulnerability reporting feature if enabled, or contact the maintainer privately before sharing sensitive material.

If you exposed a Muse SDK token or device credentials, revoke the affected authorization through Muse. If an ASR key was exposed, revoke it with that provider. Removing a value from the latest Git commit does not remove it from history.

This preview implements the upstream community pairing protocol and inherits its trust model. Review the upstream SDK's pairing documentation before using it in your own environment. Do not deploy this preview as an unattended production security boundary.
